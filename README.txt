PCB Mentor is an interactive Scilab based educational simulator for exploring PCB design through practical calculations and visualizations. It includes voltage-drop analysis, trace-width estimation, footprint exploration, basic design-rule checks, and guided learning. Users can modify engineering parameters and observe the resulting dynamics. Inspired by my first PCB design experience during a summer internship, I created PCB Mentor to make PCB concepts more accessible to the masses.
Steps to Run:
1. Download and extract the PCB Mentor ZIP file in the computer. Make sure the complete project folder structure is preserved. 
2. Install Scilab on your system, then open Scilab and navigate to the extracted PCB_Mentor folder.
3. Open the main.sce file in the Scilab editor and execute it. The application will automatically load the required functions and open the PCB Mentor dashboard.
4. From the dashboard, users can access the Trace Width Calculator, Voltage Drop Analyzer, DRC Assistant, Footprint Explorer, and PCB Learning modules.
5. Enter or modify the required parameters in each module and use the respective Calculate, Simulate, or Run button to generate updated results and visualizations.
P.S - No additional software or external libraries are required.
